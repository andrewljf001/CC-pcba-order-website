# PCBA 报价逻辑文档

## 三种订单模式

```
模式A：纯 PCB 制板
模式B：PCB + SMT 贴片
模式C：PCB + 插件 (DIP/THT)
模式D：PCB + SMT + 插件（混合 Turnkey）
```

---

## 模式A：纯 PCB 报价逻辑

### 参数
| 参数 | 选项 |
|------|------|
| 层数 | 1 / 2 / 4 / 6 / 8 / 10L |
| 尺寸 | 宽 × 高 mm（用户输入）|
| 数量 | 5 / 10 / 25 / 50 / 100 / 200 / 500 / 1000 pcs |
| 板厚 | 0.8 / 1.0 / 1.6 / 2.0mm |
| 表面处理 | HASL(LF) / ENIG / OSP / Hard Gold |
| 阻焊颜色 | 绿 / 蓝 / 红 / 黑 / 白 |
| 铜厚 | 1oz / 2oz |
| 交期 | 24H / 3天 / 5天 / 7天 |

### 价格公式
```
面积系数 = (宽 × 高) / 10000   （基准 100×100mm = 1.0）
基础板费 = 层数基价 × max(0.5, 面积系数) × 数量折扣 × (数量/10)
层数基价: {1:8, 2:12, 4:28, 6:55, 8:90, 10:160}
数量折扣: {5:1.0, 10:1.0, 25:0.85, 50:0.72, 100:0.6, 200:0.5, 500:0.42, 1000:0.35}
总价 = 基础板费 + 表面处理附加 + 铜厚附加 + 交期附加 + 运费
```

---

## 模式B：SMT 贴片报价逻辑

### 参数
| 参数 | 说明 |
|------|------|
| 独特料号数 (Unique Parts) | 不同元件种类数，影响首件/开机费 |
| 贴片点数 (SMT Points) | 所有贴片焊点总数，影响加工费 |
| 贴片面 | 单面 / 双面（双面 × 1.6）|
| 最小封装 | 0402标准 / 0201精细(+15%) / 01005超精细(+35%) |
| 钢网 | 新制钢网 $25 / 客供钢网 $0 |
| 元件供应 | Turnkey（我方采购）/ 客供（客户提供）|

### 价格公式
```
开机费 = unique_parts × $1.5   （最低 $30）
贴片费 = smt_points × $0.008  （0402基准）
封装系数: {0402:1.0, 0201:1.15, 01005:1.35}
双面系数: 单面=1.0, 双面=1.6
SMT小计 = (开机费 + 贴片费) × 封装系数 × 双面系数 + 钢网费

元件代购（Turnkey）= BOM总价 × 1.15  （报价后单独确认）
```

---

## 模式C：插件 (DIP/THT) 报价逻辑

### 参数
| 参数 | 说明 |
|------|------|
| 插件点数 (DIP Points) | 所有插件焊点总数 |
| 焊接方式 | 波峰焊 / 手工焊 |
| 元件供应 | Turnkey / 客供 |

### 价格公式
```
波峰焊: dip_points × $0.012
手工焊: dip_points × $0.025
DIP小计 = 点数费 + 固定开机费($20)
```

---

## 模式D：SMT + 插件混合

```
混合总价 = PCB费 + SMT费 + DIP费 + 钢网费 + 运费
（各模块独立计算后求和）
```

## 所需文件清单

| 订单模式 | 必需文件 | 可选文件 |
|---------|---------|---------|
| 纯 PCB | Gerber 文件 | 钻孔文件（通常包含在 Gerber 内）|
| PCB+SMT | Gerber + BOM 表 + 坐标文件(CPL) | 原理图 |
| PCB+DIP | Gerber + BOM 表 | 装配图 |
| 全流程 | Gerber + BOM + CPL + 装配图 | 原理图、测试程序 |

## BOM 表格式要求
```
必需字段: Ref(位号) | Qty(数量) | Part Number(料号) | Description(描述) | Package(封装)
推荐字段: Manufacturer | MPN | Supplier | Supplier PN
```

| 项目 | 说明 |
