## 一、PCB 标准报价（三档，其余全部人工报价）

标准报价为**固定起价**，不按面积/数量浮动，仅供参考，最终由工程师确认。

| 档位 | 价格 | 条件 |
|------|------|------|
| 一档 | **$50** | FR4，板厚 0.6～2.0mm，钻孔 ≥ 0.3mm，**不含阻抗控制**，层数 ≤ 4L，尺寸 ≤ 20×20cm，数量 ≤ 10片 |
| 二档 | **$75** | FR4，板厚 0.6～2.0mm，钻孔 ≥ 0.3mm，**含阻抗控制**，层数 ≤ 4L，尺寸 ≤ 20×20cm，数量 ≤ 10片 |
| 三档 | **$100** | FR4，板厚 0.6～2.0mm，钻孔 0.2mm 或 0.25mm，**含阻抗控制**，层数 ≤ 4L，尺寸 ≤ 20×20cm，数量 ≤ 10片 |

**层数选项：1L / 2L / 4L / 6L / 8L**（只有双数，选 6L 或 8L 自动触发人工报价）

**触发人工报价（任一满足）：**
- 层数 > 4L（6L、8L 等）
- 材质非 FR4
- 板厚超出 0.6～2.0mm 范围
- 钻孔 < 0.2mm
- 尺寸 > 20cm × 20cm
- 数量 > 10片

**文件要求：**
Gerber 文件须包含叠层说明与阻抗控制说明（未来网站挂模板文档）

## 二、SMT + DIP 标准报价（全包价，其余全部人工报价）

标准单为**全包价**，包含：SMT 贴片 + 插件（≤ 100脚）+ 钢网费 + AOI 检测，不随元件数量浮动。

| 档位 | 价格 | 条件 |
|------|------|------|
| 单面 | **$200** | 数量 ≤ 10片，SMT 贴片点数 ≤ 200，复杂 IC < 10个，单面贴片，元件客供 |
| 双面 | **$400** | 数量 ≤ 10片，SMT 贴片点数 ≤ 200，复杂 IC < 10个，双面贴片，元件客供 |

**包含项目：**
- 插件 ≤ 100脚：含在上述全包价内，不另收费
- 钢网费：含在全包价内
- AOI 检测：标准包含

**触发人工报价（任一满足）：**
- 数量 > 10片
- SMT 贴片点数 > 200
- 复杂 IC ≥ 10个（BGA / QFN / LGA / BTC 等不可视焊点封装）
- 插件脚数 > 100
- 元件选代采（Turnkey）

**不接受订单类型：**
- ❌ 纯插件板（无 SMT）
- ❌ 电源板
