## 一、业务定位

**精品服务路线，不与嘉立创拼平台：**
- 真人客服响应，WhatsApp 直接沟通
- **核心竞争力：PCBA 功能测试 + 远程调试支持**
  - 每块 PCBA 出货前通电功能验证
  - 远程配合开发/小批量客户进行调试
  - 客户收到的是可以直接用的板子
- 灵活小批量（1～20片），一条龙省心
- 海外客户友好：英文沟通、PayPal付款、DHL直发美国免运费
- 所有 PCB 符合 RoHS 标准，无有铅选项

---

## 二、接单流程

```
客户填写询价表 → 系统判断是否人工报价
    ↓ 普通订单                    ↓ 人工报价订单
24小时内邮件/WA报价        显示"我们会在24小时内联系你"
    ↓
客户确认 → 付款（PayPal）→ 生产+测试 → 发货（免运费到美国，约7个工作日）→ 完成
```

## 三、询价表字段（quote.html）

### 3.1 客户信息
- Name / Email / WhatsApp

### 3.2 服务类型
- PCB Only / PCB + SMT / PCB + SMT + DIP / Turnkey

### 3.3 PCB 参数
| 字段 | 选项 | 备注 |
|------|------|------|
| 层数 | 1 / 2 / 4 / 6 / 8+ | 8+ 触发人工报价 |
| 尺寸 | 长 × 宽（mm） | 数字输入 |
| 数量 | 数字输入 | >20 触发人工报价 |
| 板厚 | 0.8 / 1.0 / 1.2 / **1.6（默认）** / 2.0mm | |
| 板材 | FR4 / FR4 High-Tg / Aluminum / Rogers / PTFE / Flex / Rigid-Flex / Other | Rogers/PTFE/Flex/Rigid-Flex/Other 触发人工报价 |
| 表面处理 | LeadFree HASL / ENIG | 无有铅（RoHS） |
| 铜厚 | 1oz（固定，页面注明） | 2oz需求写备注 |
| 颜色 | Green / Blue / Red / Yellow / Black / White | |

### 3.4 SMT + DIP 参数
| 字段 | 说明 |
|------|------|
| SMT 贴片点数 | 数字输入，没有填 0，>200 触发人工报价 |
| DIP 插件点数 | 数字输入，没有填 0，>100 触发人工报价 |
| 贴片面 | 单面 $200 / 双面 $400（SMT>0时显示） |

### 3.5 元件供应
- 代采（客户上传 BOM，我方采购，费用另议）
- 客供（客户自己寄元件）

### 3.6 测试服务（独立收费，选了触发人工报价）
- No Testing Required
- Functional Testing（出货前通电功能验证）
- Remote Debug Assistance（远程配合客户调试）
- Functional Testing + Remote Debug

### 3.7 文件上传
- Gerber（必传）/ BOM / 坐标文件

### 3.8 备注
- 特殊需求文本框（有内容触发人工报价）

## 四、人工报价触发条件

| 条件 | 原因 |
|------|------|
| 数量 > 20 | 批量价格需确认 |
| 层数 = 8+ | 高层板工艺复杂 |
| 板材 = Rogers / PTFE / Flex / Rigid-Flex / Other | 特殊板材成本波动 |
| SMT点数 > 200 | 超出标准作业范围 |
| DIP点数 > 100 | 超出免费范围 |
| 测试服务 ≠ none | 测试方案需人工沟通 |
| 备注框有内容 | 客户有特殊需求 |

## 五、定价逻辑

### SMT 贴片
| 项目 | 价格 | 包含范围 |
|------|------|----------|
| 单面贴片 | 起价 $200 | ≤200点，IC类元件≤10个 |
| 双面贴片 | 起价 $400 | 每面≤200点，IC类元件≤10个 |
| 超出范围 | 人工报价 | — |

### DIP 插件
| 项目 | 价格 |
|------|------|
| ≤100点 | 免费（手焊，不过波峰） |
| >100点 | 人工报价 |

### 运费
- 美国免运费，费用含在报价中
- 运输时间约7个工作日，DHL/FedEx

### 测试服务
- 根据客户测试需求单独报价

### PCB 板费
- 根据层数、板材、尺寸、数量综合报价

### 元件代采
- 按实际采购成本+服务费（与客户直接谈）
