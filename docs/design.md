## 一、业务定位

精品小批量路线，核心优势是减少客户麻烦：
- 真人工程师响应，WhatsApp 直接沟通
- **核心竞争力：功能性验证 + 专属工程师远程调试支持**
- 灵活小批量（样品 ≤10片），一条龙省心
- 海外客户友好：英文沟通、PayPal / PingPong 付款
- 所有 PCB 符合 RoHS 标准

- 徽章：`FROM $50`

### ② PCB + SMT Assembly

### ③ Full Turnkey + Testing
- 徽章：`ENGINEER VERIFIED`

## 三、服务包含关系

```
PCB 制板
    ↑ 必须包含（不能只做贴片/插件而 PCB 外发）
PCB + SMT 贴片 / 插件
    ↑ 必须包含（功能验证必须做完整板）
Full Turnkey + Testing
```

| 组合 | 是否可接 |
|------|---------|
| 只做 PCB | ✅ |
| PCB + SMT/插件 | ✅ |
| PCB + SMT/插件 + 功能验证 | ✅ |
| 只做 SMT/插件（PCB 外发） | ❌ 不接 |
| 纯插件板（无 SMT） | ❌ 不接 |
| 电源板 | ❌ 不接 |

## 四、报价逻辑

### 4.1 PCB 标准报价（两档，其余全部人工报价）

| 档位 | 条件 | 最低价 |
|------|------|--------|
| 一档 | FR4，钻孔 ≥0.3mm，无阻抗控制，≤10片，≤20×20cm | $50 |
| 二档 | FR4，钻孔 0.2mm 或 0.25mm，含阻抗控制，≤10片，≤20×20cm | $100 |
| 其余 | 任意条件不符合 | 人工报价 |

### 4.2 SMT 标准报价（其余全部人工报价）

| 条件 | 价格 |
|------|------|
| ≤10片，元件总数 <200，复杂 IC <10个，单面贴片 | $200 |
| ≤10片，元件总数 <200，复杂 IC <10个，双面贴片 | $400 |
| 插件 ≤100脚（需有 SMT） | 不另收费 |
| 其余 | 人工报价 |

### 4.3 Full Turnkey + Testing
- 全部人工报价，无标准价

### 4.4 元件代采
- 全部人工报价

## 五、系统自动判断逻辑

客户填写参数后，系统实时判断：

```
客户填写参数
    ↓
符合标准报价条件？
    ↓ 是                        ↓ 否
显示标准报价金额          显示"需要人工报价"
客户在线支付              提示 24 小时内联系客户
```

**触发人工报价的条件：**
- 数量 > 10片
- 板材非 FR4
- 尺寸超过 20×20cm
- 选择 Full Turnkey + Testing
- 元件代采
- SMT 元件总数 ≥ 200
- 复杂 IC ≥ 10个
- 插件脚数 > 100
- 纯插件板 / 电源板

## 七、下单流程

### 标准单
```
填表 → 系统自动报价 → 在线支付（PayPal / PingPong）
→ 生产（约1周）→ 完成后报运费 → 客户补付运费 → 发货（约1周）→ 完成
```

### 非标单（人工报价）
```
填表 → 提示人工报价 → 工程师联系客户（24小时内）→ 双方确认价格
→ 客户转账 → 生产（约1周）→ 完成后报运费 → 客户补付运费 → 发货（约1周）→ 完成
```
