# CC PCBA 订单网站 — 功能模块设计

> 最后更新：2026-05-25  
> 状态：✅ 定稿

---

## 一、客户前台

### 1.1 首页
- Hero Banner：品牌定位 + 一句话说明服务 + CTA按钮（Get a Quote）
- 服务模式快速介绍（PCB / SMT / 插件 / Turnkey 四块）
- 下单流程图（5步：上传文件 → 获取报价 → 确认下单 → 付款 → 追踪进度）
- 工艺能力亮点（最小封装/层数/交期）
- 客户信任背书（可后期添加）

### 1.2 报价计算器（四模式）
- **PCB模式**：层数 / 板材 / 尺寸 / 数量 / 表面处理 / 阻焊颜色
- **SMT模式**：贴片点数 / unique parts数 / 单双面 / 数量
- **插件模式**：DIP点数 / 是否波峰焊 / 数量
- **混合模式**：SMT + 插件同时配置
- 实时前端计算出价，无需后端
- WhatsApp一键发送报价单（预填消息链接）

### 1.3 询价下单页
- 填写需求（选择服务类型 / 数量 / 备注）
- 上传文件（Gerber / BOM / Pick&Place坐标文件）
- 文件存储至 Cloudflare R2
- 填写联系信息（姓名 / 邮箱 / WhatsApp）
- 提交后：邮件通知运营，客户收到受理确认邮件

### 1.4 支付页
- 显示正式报价明细
- 选择支付方式：
  - PayPal（小单，跳转PayPal完成支付，自动确认）
  - PingPong B2B（大单，显示汇款信息，人工确认到账）
- 支付成功后订单状态自动更新为"已付款"

### 1.5 订单追踪页
- 输入订单号查询进度
- 显示当前状态及历史节点：
  ```
  询价收到 → 报价发出 → 已付款 → 生产中 → 品检 → 已发货 → 完成
  ```
- 显示物流单号（发货后）

### 1.6 工艺能力页
- PCB制板参数表（层数/线宽线距/最小孔径/板厚/表面处理等）
- SMT能力（最小封装0201/01005，单双面，AOI/X-Ray检测）
- IPC标准等级说明（Class 1/2/3）
- 文件要求说明（各模式需要哪些文件，格式要求）

## 二、运营后台（Strapi）

### 2.1 报价参数管理
- PCB单价参数（按层数/板材/工艺分类，可随时修改）
- SMT贴片单价（按点数区间定价）
- 插件单价（按点数定价）
- 改完即时生效，前台计算器自动使用最新参数

### 2.2 订单管理
- 订单列表（按状态筛选/时间排序）
- 订单详情：
  - 客户信息
  - 需求参数
  - 上传文件下载
  - 报价记录
  - 支付状态
  - 供应商信息（发给哪家厂 / 供应商订单号）
- 操作：发出报价 / 确认收款 / 更新状态 / 填写物流单号

### 2.3 供应商管理
- 供应商列表（名称/联系方式/擅长类型）
- 每个订单可指定供应商
- 记录供应商订单号（用于本地同步工具映射）

### 2.4 文件管理
- 查看/下载客户上传的所有文件
- 按订单归类
- 文件存储在 Cloudflare R2，后台显示下载链接

### 2.5 网站内容管理
- 工艺能力参数（可编辑更新）
- 首页文案（可编辑）
- 公告/通知（可选）

## 三、本地同步工具（Mac）

### 3.1 核心功能
- 用 Playwright 控制本地 Chrome 浏览器
- 登录供应商后台（复用浏览器本地登录状态，不存密码）
- 抓取订单状态
- 通过 API 推送到网站数据库

### 3.2 订单号映射
- 本地维护映射表：网站订单号 ↔ 供应商订单号
- 支持一个网站订单对应多个供应商订单（拆单场景）

### 3.3 供应商适配器（可插拔）
- 嘉立创适配器（第一期）
- 其他供应商适配器（后期按需添加，不影响现有逻辑）
- 降级策略：
  1. 有API → 直接调API
  2. 无API → Playwright全自动抓取
  3. 无法自动化 → 打开网页手动操作，工具只同步结果

### 3.4 运行方式
- Mac菜单栏常驻工具
- 支持定时自动同步（每X分钟）
- 支持手动触发同步

## 四、基础设施

| 组件 | 方案 | 说明 |
|------|------|------|
| 前台+后台 | VPS 4GB（新加坡） | Hetzner 或 DigitalOcean |
| 数据库 | PostgreSQL | Strapi默认，部署在VPS |
| 文件存储 | Cloudflare R2 | 客户上传文件，免费10GB起 |
| CDN | Cloudflare | 免费套餐 |
| 邮件服务 | Resend 或 SendGrid | 订单通知邮件 |
| 支付 | PayPal API + PingPong B2B | 小单自动/大单人工 |
| 本地工具 | Node.js + Playwright | 运行在你的Mac |
