## 二、客户前台功能模块

### 2.1 首页
- Hero Banner：公司定位 + 核心服务 + CTA 按钮
- 服务模式卡片：纯PCB / SMT贴片 / 插件DIP / Turnkey一条龙
- 下单流程图：5步走（询价→确认→支付→生产→收货）
- 客户信任背书：交付数量、客户评价、认证资质

### 2.2 工艺能力页
- PCB制板参数表（层数/板材/线宽线距/孔径/表面处理）
- SMT贴片能力（最小封装 0201/01005，单双面，AOI/X-Ray检测）
- 插件能力（波峰焊/手工焊，IPC等级）
- 文件要求说明（各模式需要哪些文件）

### 2.3 报价计算器
- 四种模式切换：PCB / SMT / 插件 / 混合
- 实时前端计算，无需后端
- 计算结果可一键发送到 WhatsApp
- 报价参数从后台动态读取（市场波动可随时调整）

**PCB 报价参数：**
层数 / 板材（FR4/铝基/高频）/ 尺寸 / 数量 / 表面处理 / 最小线宽 / 颜色

**SMT 报价参数：**
独特料号数量（Unique Parts）/ 贴片点数 / 单双面 / 数量

**插件报价参数：**
DIP点数 / 是否波峰焊 / 数量

**混合模式：**
SMT + 插件同时配置

### 2.4 询价下单页
- 填写需求表单（基本信息 + 订单备注）
- 文件上传（Gerber / BOM / Pick&Place坐标文件）
- 提交后发送确认邮件给客户
- 提交后通知运营（邮件/WhatsApp）

### 2.5 支付页
- 运营发出正式报价后，客户收到含支付链接的邮件
- PayPal：小单，客户自助完成支付
- PingPong B2B：大单，显示电汇账户信息，运营人工确认到账

### 2.6 订单追踪页
- 客户凭订单号查询当前状态
- 状态时间轴展示：询价 → 报价 → 付款确认 → 生产中 → 品检 → 发货 → 完成
- 发货后显示快递单号和物流链接

## 三、运营后台功能模块

### 3.1 网站内容管理
- 报价参数管理（随市场波动随时调整单价）
- 工艺能力参数管理
- 首页内容管理（Banner/公告）

### 3.2 询价管理
- 新询价列表（未处理）
- 下载客户上传文件（Gerber/BOM/坐标）
- 填写正式报价并发送给客户

### 3.3 订单管理
- 订单列表（全部/按状态筛选）
- 订单详情（客户信息/需求/文件/报价/支付记录）
- 订单状态手动更新
- 记录发给哪个供应商 + 供应商订单号（映射表）
- 填写快递单号

### 3.4 支付管理
- PayPal 收款自动确认
- PingPong B2B 人工标记到账
- 收款记录列表

### 3.5 供应商管理
- 供应商列表（名称/类型/联系方式/适配器状态）
- 每个订单的供应商分配记录
- 本地同步工具连接状态

### 3.6 文件管理
- 客户上传文件（按订单分类）
- 生产相关文件上传（测试报告/出货照片）

## 四、本地同步工具（Mac App）

### 4.1 核心机制
```
网站订单号（CC-2026-001）
        ↕  映射表
供应商订单号（嘉立创：JLC-XXXXXXXX）
```

### 4.2 工作流程
1. 运营在后台分配供应商并录入供应商订单号
2. 本地工具读取映射表
3. Playwright 自动登录供应商网页后台
4. 抓取对应订单的生产状态
5. 通过 API 推送到网站数据库
6. 客户前台实时显示最新进度

### 4.3 供应商适配器（可插拔）
- **嘉立创适配器**（第一期，优先实现）
- 捷配适配器（按需扩展）
- 其他供应商（按需扩展）

### 4.4 降级策略
```
优先：Playwright 全自动（有网页后台的供应商）
降级：Playwright 辅助 + 人工操作（复杂验证码场景）
兜底：人工在后台手动更新状态
```

## 五、业务闭环完整流程

```
客户                              运营                         供应商
  │                                │                              │
  ├─ 报价计算器估价                  │                              │
  ├─ 提交询价 + 上传文件  ─────────→ 收到通知                       │
  │                                ├─ 下载文件审核                  │
  │                                ├─ 发出正式报价                  │
  ←─ 收到报价邮件 ─────────────────┤                              │
  ├─ 确认 + 支付（PayPal/PingPong） │                              │
  │                         ───→  确认收款                        │
  │                                ├─ 分配供应商                   │
  │                                ├─ 本地工具下单  ─────────────→ 接单生产
  ←─ 收到生产开始通知 ──────────────┤                              │
  │                                │  ←─ 本地工具自动同步状态 ──────┤
  ←─ 实时查看订单进度 ──────────────┤                              │
  │                                ├─ 填写快递单号                  │
  ←─ 收到发货通知 + 单号 ───────────┤                              │
  └─ 确认收货                       └─ 订单归档                     │
```
