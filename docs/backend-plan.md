# CC PCBA 订单网站 — 技术架构方案

> 最后更新：2026-05-25  
> 状态：✅ 定稿

---

## 一、整体架构

```
┌─────────────────────────────────────────────────┐
│  客户浏览器                                       │
│  前台网站（HTML/CSS/JS）                          │
└───────────────────┬─────────────────────────────┘
                    │ HTTPS
┌───────────────────▼─────────────────────────────┐
│  VPS（新加坡，4GB内存）                            │
│  ├─ Nginx 反向代理                               │
│  ├─ 前台静态文件服务                              │
│  ├─ Strapi v5（运营后台 + API）                   │
│  └─ PostgreSQL（订单/报价/客户数据）               │
└───────────────────┬─────────────────────────────┘
                    │
        ┌───────────┴───────────┐
        │                       │
┌───────▼────────┐   ┌──────────▼──────────┐
│ Cloudflare R2  │   │  Cloudflare CDN      │
│ 客户上传文件    │   │  静态资源加速         │
│ Gerber/BOM等   │   │  全球访问加速         │
└────────────────┘   └─────────────────────┘

┌─────────────────────────────────────────────────┐
│  你的 Mac（本地）                                 │
│  ├─ 本地同步工具（Node.js + Playwright）          │
│  ├─ 供应商适配器（嘉立创 / 其他）                  │
│  ├─ 订单号映射表（本地存储）                       │
│  └─ 定时推送状态到 VPS API                        │
└─────────────────────────────────────────────────┘
```

## 二、VPS 配置

| 项目 | 规格 |
|------|------|
| 内存 | 4GB |
| CPU | 2核 |
| 系统盘 | 40GB SSD |
| 带宽 | 20Mbps |
| 位置 | 新加坡（覆盖欧美延迟可接受，亚洲最优） |
| 推荐服务商 | Hetzner（最性价比）/ DigitalOcean |

## 三、技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前台 | HTML + CSS + JS | 纯静态，极客绿黑风，延续现有风格 |
| 后台 CMS | Strapi v5 | 自托管，内容管理 + API |
| 数据库 | PostgreSQL | Strapi默认，稳定可靠 |
| 文件存储 | Cloudflare R2 | 零出口费用，免费10GB |
| CDN | Cloudflare | 免费套餐足够 |
| 反向代理 | Nginx | SSL终止 + 静态文件服务 |
| 邮件服务 | Resend | 简单接入，有免费额度 |
| 支付 | PayPal API + PingPong B2B | 小单自动/大单人工 |
| 本地工具 | Node.js + Playwright | Mac本地运行 |

---

## 四、数据存储分工

| 数据类型 | 存储位置 | 原因 |
|---------|---------|------|
| 订单信息 / 报价记录 / 客户信息 | VPS PostgreSQL | 核心业务数据，需要查询关联 |
| 客户上传文件（Gerber/BOM/坐标） | Cloudflare R2 | 大文件，便宜，全球CDN加速 |
| 供应商账号 / 订单号映射表 | 你的Mac本地 | 安全，不上服务器 |
| 数据库备份 | Backblaze B2（异地） | 灾备，极便宜 |

## 五、订单状态流转

```
询价收到
    ↓
报价发出（运营人工核价后操作）
    ↓
客户确认报价
    ↓
已付款
├─ PayPal → 系统自动确认
└─ PingPong B2B → 人工后台确认
    ↓
生产中（本地工具从供应商同步状态）
    ↓
品检中
    ↓
已发货（运营填写物流单号）
    ↓
完成
```

## 六、本地同步工具架构

```
sync-tool/
├─ index.js              # 主入口，定时任务
├─ api.js                # 推送状态到网站的API客户端
├─ mapping.json          # 订单号映射表（本地持久化）
└─ adapters/
    ├─ base.js           # 适配器基类（统一接口）
    ├─ jlcpcb.js         # 嘉立创适配器（第一期）
    └─ [vendor].js       # 其他供应商（按需扩展）
```

**适配器统一接口：**
```javascript
// 每个适配器必须实现这两个方法
adapter.login()                    // 登录供应商后台
adapter.getOrderStatus(orderId)    // 根据订单号获取状态
```

**三级降级策略：**
1. 有开放API → 直接调API（最稳定）
2. 无API → Playwright自动化操作网页
3. 无法自动化 → 打开网页让你手动操作，工具只负责同步结果

---

## 七、安全策略

- 供应商账号密码只存在Mac本地，不上VPS
- VPS只开放80/443/SSH端口
- Strapi后台只允许指定IP访问（你的IP）
- Cloudflare R2文件通过签名URL访问，不公开直链
- 数据库每日自动备份到异地
